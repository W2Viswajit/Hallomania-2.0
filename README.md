# HalloMania 2.0

The official HalloMania 2.0 event website, hosted by **AUGMENTIX**, the student club of the Department of Artificial Intelligence & Data Science at **Nitte Meenakshi Institute of Technology (NMIT)**.

HalloMania is a Halloween-themed tech carnival with interactive challenges in debugging, AI detection, and logic mysteries.

## Event details

- **Date:** 6 November 2026
- **Venue:** NMIT Campus, Bengaluru
- **Eligibility:** College students from any branch or year
- **Team size:** 2–4 participants
- **Registration fee:** ₹250 per team, per event
- **Prize pool:** ₹60,000 total

### Events

| Event | Time | Challenge |
|---|---|---|
| Digital Exorcism | 11:00 AM–12:15 PM | Debug corrupted code and uncover clues in logs |
| Phantom's Prophecy | 12:15–1:45 PM | Identify AI-generated content, predict code output, and solve a cryptic grid |
| The Killer Circuit | 2:15–3:15 PM | Solve a murder mystery using logic gates and evidence |

Each event awards ₹10,000 for first place, ₹7,000 for second, and ₹3,000 for third.

## Website features

- Responsive event landing page with an event countdown
- Event schedules, rules, FAQs, and registration links
- Halloween-inspired visuals and animations
- Reduced-motion support

## Run locally

This is a static website; there is no build step or package installation.

1. Clone or download this repository.
2. Open `main.html` in a browser.

Alternatively, run a local server from the project folder:

```powershell
py -m http.server 8000
```

Then visit [http://localhost:8000/main.html](http://localhost:8000/main.html).
